# MathUniverse Expansion Master Orchestration Plan

## 1. Objectives & Scope
Expand MathUniverse with four core modules:
1. **R1: Client-Side Interactive Mathematical Computation Sandbox** (Pyodide / SymPy worker integration, parameter sliders, live 2D/3D plots, numerical verification for math nodes).
2. **R2: Gamified Mathematical Progression & Fallacy Detective** (ZFC to Modern Math RPG campaign tree, axiom unlocking & validation, and Mathematical Fallacy Detective interactive lab with subtle flaw diagnosis).
3. **R3: Advanced 3D WebGL / GPU Knowledge Cosmos & Prerequisite Pathway** (3D WebGL particle/force-directed layout clustering disciplines into nebulae, flythrough navigation, minimum prerequisite closure path algorithms & visualization).
4. **R4: Academic Publishing & Toolchain Exporter** (LaTeX / Typst / Overleaf / Markdown compiling theorem nodes with recursive prerequisite trees).

## 2. Orchestration Strategy
Following the Project Pattern:
- **Phase 0: Survey**: 3 parallel Explorers survey the codebase, dependencies, data structures, and existing capabilities.
- **Phase 1: Architecture & Scope Finalization**: Merge inventory into `PROJECT.md`, establish module contracts, code layout, and test requirements.
- **Phase 2: Milestone Execution**:
  - Independent milestone execution with dedicated Explorer -> Worker -> Reviewer -> Challenger -> Auditor verification loops.
  - Concurrent E2E Testing Track ensuring opaque-box acceptance testing across 4 tiers.
- **Phase 3: Final Acceptance Gate**: 100% build clean (`npm run build`), 100% existing tests passing (`npm test`), all new unit/integration tests passing, clean forensic audit.

- `.agents/worker_m1/`, `.agents/reviewer_m1_1/`, etc. for milestone subagents.
